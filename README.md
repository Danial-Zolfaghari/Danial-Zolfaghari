## About

I'm **Danial Zolfaghari**, a computer engineer working across **Incident Response, EOC/SOC/NOC operations, network security, traffic analysis, backend development, automation, monitoring, and applied AI**.

My work is usually where operations and engineering meet: analyzing network behavior, responding to incidents, working with L3/L4 traffic and DDoS scenarios, building internal tools and APIs, designing monitoring and analysis workflows, and automating repetitive operational tasks.

I also work on data-heavy systems where **Elasticsearch, databases, backend services, and local AI/LLM pipelines** need to cooperate in a deterministic and auditable way.

- Evidence-based answer generation
- Tool / planner pipelines
- Long-lived knowledge and mapping layers such as a **World Map**

## How I Usually Approach Engineering

I prefer systems that are:

- **observable** — failures should be visible and explainable
- **deterministic where possible** — especially around automation and AI
- **secure by default**
- **evidence-driven**
- **modular and maintainable**
- **practical for real operations**
- **clear about limitations**
- **built to survive real-world failure modes**
